# Customer Call List Data Cleaning

## Project Overview
This project demonstrates basic data cleaning using Python and Pandas to prepare a customer call list for analysis and outreach.

## Tasks Performed
- Removed duplicate records and unnecessary columns.
- Cleaned and standardized customer names and phone numbers.
- Split address information into separate fields.
- Standardized categorical values.
- Handled missing data and filtered out customers who could not be contacted.
- Reset the dataset index after cleaning.

## Tools Used
- Python
- Pandas
- Google Colab

## Project Files
- customer_call_list_data_cleaning.ipynb
- Customer Call List.xlsx

## Objective
To improve data quality and prepare a structured, consistent dataset suitable for customer outreach and further analysis.
